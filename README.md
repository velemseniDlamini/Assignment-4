# 📝 My Django Blog & Project Website

Hi there! 👋  
This is a web application I built using Django. It's designed to manage blog posts and showcase different projects. It also includes user authentication, file uploads, and a MySQL database.

## 🔍 What's Inside?

Here’s a quick breakdown of what you’ll find in this project:

- **accounts/** – Handles user login, registration, and authentication
- **project/** – Manages the portfolio/project sections
- **media/** – Stores uploaded files
- **my_blog_db.sql / mysql.sql** – MySQL database structure
- **.vscode/** – My editor setup (you can ignore this if you're not using VS Code)
- **Pipfile / requirements.txt** – All the Python packages used
- **manage.py** – The main Django command-line utility

> There's also a `blog/` folder that used to be part of the project but I’ve removed its contents as they were no longer needed.

## 💡 Features

- Clean and responsive frontend with HTML/CSS
- Users can sign up, log in, and manage content
- Project showcase section
- Media upload support
- MySQL database with ER diagram
- GitHub Actions setup for automation
